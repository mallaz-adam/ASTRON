# Unit 4 galaxy observations

Retrieved 2 November 2026. These are real observations, not generated images.
Each screen-sized source was resized to at most 1000 pixels and compressed as
WebP, without recolouring or cropping. The four files total 276262 bytes.
`provenance.json` records URLs, source hashes, original/local dimensions and changes.

These observations use processed colour. The Andromeda image is ground-based
DSS2 data, not a Hubble exposure. The deep field combines many observations;
not every bright point is a background galaxy.
