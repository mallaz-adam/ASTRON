# Solar-system observation images

Retrieved and checked on 30 October 2026. Local files are resized WebP copies,
up to 600 pixels on the longer side, without recolouring. These are spacecraft
observations, including processed composites and mosaics, not generated art.
`provenance.json` records exact original downloads, dimensions and file sizes.
